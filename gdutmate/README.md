# GDUTmate MVP Demo

基于原 CompMate Demo 调整的大学生竞赛组队交互演示，版本 v31。

- 首页：功能入口、队伍推荐、队友推荐、待处理事项入口。
- 寻找：队伍按可报名时间段、竞赛、岗位与能力筛选；队友仅按岗位与能力筛选。同项多选为“或”，不同项为“且”。
- 我的帖子：个人资料同步生成，可编辑、暂停或开启展示。
- 管理：待处理、已组队、已结束；申请与招募邀请、双方授权联系方式（模拟）、审核结果、成员管理。
- 发布招募：多岗位、能力要求、任务、人数和日期；无时间容量、认证或参赛目标功能。
- 我的：基础资料、反馈、修改密码与注销申请。

静态网页，不需要构建。使用 `python3 -m http.server 8000` 后打开浏览器。

所有用户、队伍及联系方式均为演示数据。数据保存在当前浏览器 localStorage，不含真实登录、后端、多用户同步或管理员接收服务。不要输入真实密码。

“演示设置”可模拟另一方响应、预览学号登录、重置示例数据。实际产品需要后端身份验证、权限校验及双方联系方式授权。

## v30 核对修订

- 修复表单辅助按钮误提交，筛选表按日期、竞赛、岗位联动。
- 报名开始前不可申请；招募状态统一展示未开始、已截止、已关闭和名额已满。
- 申请审核增加公开资料入口；本人不能代替受邀者接受自己发出的邀请。
- 统一名额口径，退出与移除同步更新成员；解散保留已有结束原因。
- 帖子编辑保存后返回原入口，手机端可进入演示设置。
- 模拟成功与失败均归入现有三个状态，不增加中间状态。

## v31 界面精简

- 首页提供我的队伍和待处理事项入口。
- 详情页返回原入口；取消发布返回来源页面。
- 统一组队记录、拒绝邀请、暂停展示等用词。
- 调整发布表单分行与日期提示，技能输入提供简短示例。
