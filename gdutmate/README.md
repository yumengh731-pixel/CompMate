# GDUTmate MVP Demo

基于原 CompMate Demo 调整的大学生竞赛组队交互演示，版本 v29。

- 首页：功能入口、队伍推荐、队友推荐、比赛日历入口。
- 寻找：队伍按可报名时间段、竞赛、岗位与能力筛选；队友仅按岗位与能力筛选。同项多选为“或”，不同项为“且”。
- 我的帖子：个人资料同步生成，可编辑、暂停或开启展示。
- 管理：待处理、已组队、已结束；申请与招募邀请、双方授权联系方式（模拟）、审核结果、成员管理。
- 发布招募：多岗位、能力要求、任务、人数和日期；无时间容量、认证或参赛目标功能。
- 我的：基础资料、反馈、修改密码与注销申请。

静态网页，不需要构建。使用 `python3 -m http.server 8000` 后打开浏览器。

所有用户、队伍、联系方式及日历日程均为演示数据。数据保存在当前浏览器 localStorage，不含真实登录、后端、多用户同步或管理员接收服务。不要输入真实密码。

“演示设置”可模拟另一方响应、预览学号登录、重置示例数据。实际产品需要后端身份验证、权限校验及双方联系方式授权。
