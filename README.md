# GDUTmate MVP Demo v35

基于已确认首页布局，按 MVP 需求精简：

- 首页保留大标语、比赛日历 / 我的队伍 / 待办并列入口，以及队伍和队友推荐。
- 队伍筛选按可报名时间段、竞赛、岗位与能力排列；同一字段多选为或，不同字段为且。
- 找队友仅按能力、岗位筛选；我的帖子置顶，资料同步，支持暂停展示。
- 管理仅待处理、已组队、已结束。双方授权后查看联系方式，平台外沟通后由队长确认结果。
- 移除时间容量、认证、参赛目标、协作预期及入群说明的界面、数据和校验。
- 发布仅包含队伍、招募、岗位及日期等必要字段；项目开始日期包含可报名时间。

静态演示，无真实登录、消息发送、后端或管理员接收服务。所有账号、联系方式及比赛日期均为演示数据；反馈与操作仅保存在当前浏览器。旧版浏览器数据使用独立键，避免废弃规则回流。

无需构建：python3 -m http.server 8000。
