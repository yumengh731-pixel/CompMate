# 竞旅 CompMate Demo

> 小A工作室秋招考核｜Alpha 交互 Demo

CompMate 是一个面向高校学生的轻量竞赛组队平台，核心解决：

- 不知道去哪里找队友 / 队伍
- 看到了陌生人，但难判断是否适合当前任务
- 组队前沟通与确认成本高

## 核心链路

**发现 → 判断 → 沟通 → 正式确认 → 组队**

## Demo 覆盖

- 组队大厅与筛选
- 招募详情与匹配理由
- 找队友 / 候选人卡
- 申请、邀请与待沟通
- 联系方式授权
- 正式组队确认
- 最小队伍页
- 个人档案
- 发布招募

## 产品取舍

Alpha 不做站内 IM、社区动态、公开能力评分、完整项目管理和复杂机器学习推荐；优先验证核心组队闭环。

## 运行

直接打开仓库根目录的 `index.html` 即可运行，无需安装依赖。

如启用 GitHub Pages，可直接作为在线 Demo 展示。
